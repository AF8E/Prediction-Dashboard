========================================
SUSTAINMENT PREDICTION DASHBOARD
Quick Start Guide
========================================

EASIEST WAY:
  Double-click "start-all.bat"

MANUAL WAY:
  Terminal 1:
    cd backend
    py -m uvicorn main:app --reload --port 8000

  Terminal 2:
    cd frontend
    npm run dev

OPEN:
  http://localhost:3000 (or 3001 if 3000 is busy)

USING THE DASHBOARD:
  1) Upload Projects file (CSV/XLSX)
  2) Upload Inventory/Key file (CSV/XLSX)
  3) Click Run Prediction
