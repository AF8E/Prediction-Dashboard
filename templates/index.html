How to Use This Dashboard

  1. Upload Data: Click "Upload New Inventory" to submit facility data in Excel or CSV format
  2. Run Predictions: The system will analyze each facility and predict failure dates
  3. Review Results: See predicted failure dates, risk levels, and estimated replacement costs
  4. Plan Maintenance: Use insights to prioritize maintenance and budget allocation
Note: Predictions are based on Random Forest machine learning models trained on historical facility data and failure patterns.
